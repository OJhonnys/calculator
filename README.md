# Python Calculator 🧮

Welcome to my Calculator repository! This is a simple project I developed as part of my programming studies. The goal is to practice fundamental Python concepts and create a functional tool.

## 🚀 About the Project

This calculator was built to perform basic mathematical operations such as:

- Addition
- Subtraction
- Multiplication
- Division

It also includes validations to handle errors, like preventing division by zero.

## 🛠️ Technologies Used

- **Language**: Python
- **Libraries**: No external libraries were used (only Python's built-in modules).

🖼️ Features
The calculator provides a menu where you can select the desired operation and perform calculations directly in the terminal.
